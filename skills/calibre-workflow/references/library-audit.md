# 书库审计与安全边界

## 审计范围

- 用 SQLite 只读连接检查 `metadata.db` 的 `quick_check`；
- 统计 `books` 和 `data` 中的书目与格式记录；
- 根据 `books.path`、`data.name`、`data.format` 检查格式文件是否存在；
- 按标准化标题归类重复候选，供人工决定是否合并；
- 报告不安全相对路径、未知 Calibre 架构或数据库读取错误。

## 不自动执行的操作

- 直接写入、修复或重建 `metadata.db`；
- 删除、移动、重命名书籍或格式；
- 合并重复书籍；
- 修改封面、作者、标签、系列、评分或阅读进度；
- 处理 DRM 或加密。

## 人工修复建议

先关闭 Calibre 并备份书库。缺失格式可在 Calibre GUI 中移除无效格式、重新导入原文件，或从备份恢复。重复候选应比较作者、系列、出版日期、格式和实际内容后再合并。完成后再次运行审计。

## 已知兼容性

首版适用于包含 `books` 与 `data` 基础表的常规 Calibre 书库。架构变化或不完整数据库会被报告，而不是强行推断。
