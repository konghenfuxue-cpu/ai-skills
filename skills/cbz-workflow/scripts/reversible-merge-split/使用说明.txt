CBZ 可逆合并与拆分工具
========================

一、新版可逆合并
----------------
1. 双击“一键多选合并CBZ.cmd”。
2. 选择两个或更多 CBZ。
3. 输入合集名称和保存位置。

新合集会在内部写入“META-INF/cbz-merge-manifest.json”还原清单。
清单保存每个原 CBZ 的：
- 原文件名和显示标题。
- 原图片路径与合并后路径对应关系。
- 原 ComicInfo.xml、ZIP 注释和其他附加文件。
- 原文件顺序和常用 ZIP 属性。

正文图片不会在合集内重复保存，只额外保留各本丢弃的封面和小型元数据，
因此合集体积不会翻倍。

二、拆分还原
------------
1. 双击“一键拆分还原CBZ.cmd”。
2. 选择合并后的 CBZ。
3. 选择输出位置。
4. 预览拆分模式和数量，输入大写 SPLIT 开始。

新版可逆合集：
- 还原原 CBZ 文件名、图片路径、ComicInfo.xml 和 ZIP 元数据。
- 图片和附加文件的内容与合并前一致。
- ZIP 压缩二进制本身可能不完全相同，但文件内容和元数据可用。

旧版已合并合集：
- 按 001、002…文件夹拆成独立 CBZ。
- 从合集简介尽量恢复书名，重建基本 ComicInfo 和页数。
- 合并时已丢失的各本原 ComicInfo、作者细节和部分封面无法找回。

三、重要注意
------------
- 合并和拆分都生成新文件，不覆盖原文件。
- 处理前关闭 Calibre、OpenComic 和占用 CBZ 的压缩软件。
- 拆分时请预留约等于合集大小的磁盘空间。
- 不要在可逆合集内手动删除 META-INF 或 .cbz-restore 目录。
- 如果修改了数字分组图片，对应原 CBZ 将无法完整还原。

环境：Windows 10/11，Python 3.10 或更高版本，无需第三方库。
