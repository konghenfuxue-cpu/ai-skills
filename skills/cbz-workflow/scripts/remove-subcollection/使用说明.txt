CBZ 删除指定子合集工具
=============================

用途
----
用于内部按 001、002、003…顶层文件夹分组的 CBZ 大合集。
可删除某一整项，例如第 16 项，并同步更新后续编号和元数据。

默认安全规则
------------
- 不修改、不覆盖原 CBZ。
- 生成“原名_已删除第016项.cbz”。
- 处理前显示项目名称、图片数、总页数变化和空间需求。
- 必须输入大写 DELETE 才会开始。
- 失败时删除不完整输出，原 CBZ 保持不变。

自动处理
--------
1. 删除指定数字分组中的所有文件。
2. 将后续顶层分组编号减一，例如 017 -> 016。
3. 从“本合集按以下顺序合并”简介清单中删除对应项。
4. 将简介后续序号重新排列。
5. 更新 ComicInfo.xml 的 Summary、PageCount 和 Pages 页面索引。
6. 更新 Calibre 使用的 ComicBookInfo ZIP 元数据。
7. 保留标题、作者、标签、系列等其他元数据。

使用方法
--------
方法一：双击“一键删除CBZ子合集.cmd”，在窗口中选择 CBZ。
方法二：将一个 CBZ 拖到 CMD 上。

然后输入要删除的项目编号，例如：

16

阅读执行前预览，确认名称和页数无误后，输入：

DELETE

空间要求
--------
生成新 CBZ 需要重写压缩包。请保留至少约等于原 CBZ 大小，
再加 128 MB 的可用空间。

处理后
------
1. 先用 OpenComic 打开新 CBZ。
2. 确认原第 16 项已消失，原第 17 项已变为第 16 项。
3. 检查前后相邻两项是否能正常阅读。
4. 确认无误后，再在 Calibre 的原书目中替换 CBZ 格式。

环境要求
--------
Windows 10/11，Python 3.10 或更高版本。
无需安装第三方 Python 库。
