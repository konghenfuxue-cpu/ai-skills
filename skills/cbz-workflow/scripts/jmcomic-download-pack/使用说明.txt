JMComic 每25话转CBZ
====================

1. 把整个“JMComic_每25话转CBZ”文件夹解压到：
   D:\JMComic\JMComic_每25话转CBZ

2. 双击“一键下载并转CBZ.cmd”，然后选择：
   1 = 输入 JM 号直接下载
   2 = 搜索作品并选择下载
   3 = 扫描已有 JPG 目录并续做 CBZ
   4 = 退出

   如果电脑在 JPG 下载完成后关闭、尚未生成 CBZ，请选择 3。
   工具会扫描 D:\JMComic\download，按 JM 号合并简体/繁体重复目录。
   输入 A 可处理全部未完成作品；输入序号可只处理某一本；R 会重新检查全部。
   已经完整生成的 CBZ 会经过 ZIP 校验后跳过，不会重复压缩。

3. 直接下载时输入纯数字 JM 号，例如：
   1194365

   搜索模式可以输入作品名、作者或标签，例如：
   社團學姊
   QRQ
   韓漫 姐姐

   搜索结果支持 N 下一页、P 上一页、S 换关键词、Q 退出。
   输入结果序号并确认后，会自动下载并转 CBZ。

4. 工具会自动：
   - 搜索时同时使用原词、简体词、繁体词，并按 JM 号合并去重；
   - 使用 JMComic 的 APP API 下载并还原 JPG 图片；
   - 自动下载作品封面；
   - 根据章节标题和图片数量识别公告，公告另存为“公告附录.cbz”；
   - 从章节标题识别实际话数，修正休刊公告造成的序号偏移；
   - 每 25 个正文话生成一个 CBZ；
   - 第一卷使用原始作品封面，后续卷自动生成“作品名＋话数范围”封面；
   - 可选择最大宽度 1440、1600、1800 或原图，默认1600；
   - 手机版统一输出 JPEG 质量85；
   - 把结果保存到 D:\JMComic\download\CBZ；
   - 每个 CBZ 生成后自动统计图片页数，并从 JMComic 作品信息读取全部作者；
   - 同时写入 ComicInfo.xml 的 PageCount、Writer、简介末尾“页数：XX 页”和 Calibre ZIP 注释；
   - 不生成“处理后”副本，也不创建页数元数据备份文件夹；
   - 生成“分卷报告.txt”。

自动写入页数元数据（本版新增）
--------------------------------

每个正文分卷和“公告附录.cbz”生成后，工具会自动完成页数和作者写入，无需再运行
“一键写入CBZ页数.cmd”。已存在且通过 ZIP 校验的分卷也会补写或更新页数与作者。

处理结果直接替换原 CBZ，不产生新的 CBZ 副本，也不会建立“_CBZ元数据备份”文件夹。
为防止写入中断损坏原文件，程序会在同目录短暂建立临时文件，校验成功后原子替换，
临时文件在成功或失败后都会自动清理。

完整性报告（本版新增）
--------------------------

每次下载后，工具会从网站读取每章应有的图片清单，并与本地文件逐页对比：

  - 完整：报告首行显示【下载状态】完整。
  - 未完成：报告首行显示【下载状态】未完成，并列出缺少的站点序号、图片文件名和损坏图片。
  - 即使 jmcomic 中途报错，工具也会继续检查现有图片并生成报告。
  - 报告位置：D:\JMComic\download\CBZ\JM号-作品名-分卷报告.txt

option.yml 已把 log 设为 false，不再保存庞大的逐图日志。小型分卷报告仍会保留。
若报告显示未完成，重新运行同一 JM 号即可利用缓存补下缺页，然后再次生成报告。

默认保留原始图片，位置为 D:\JMComic\download\JM号-作品名。
确认 CBZ 正常后，可以手动删除对应原图目录。

重复运行同一个 JM 号时，已下载图片会使用缓存，不会全部重下。

如果不使用系统代理，把 option.yml 中：
  proxies: system
改成：
  proxies: null

如需调整分卷数量，把 CMD 中 pack_cbz.py 命令后的数字 25 改成其他数字。
