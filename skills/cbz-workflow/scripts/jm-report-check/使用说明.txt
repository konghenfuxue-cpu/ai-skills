JMComic 分卷报告完整性检测工具
================================

一、最简单的使用方法

1. 双击“双击检测.cmd”。
2. 输入或粘贴包含“分卷报告.txt”的目标目录。
3. 也可以把目标文件夹拖到“双击检测.cmd”图标上。

工具会递归扫描所有子文件夹，不需要把报告集中到一起。

二、设置默认文件夹

如果设置了环境变量 JMCOMIC_DOWNLOAD_ROOT，直接按回车时默认扫描：

%JMCOMIC_DOWNLOAD_ROOT%\CBZ

PowerShell 临时设置示例：

$env:JMCOMIC_DOWNLOAD_ROOT = 'D:\你的JMComic下载目录'

未设置时，默认扫描当前工作目录。命令行也可直接指定路径：

python check_incomplete_reports.py "D:\你的报告目录"

三、检测依据

工具会同时检查：

1. 【下载状态】是否为“完整”；
2. “缺失”是否大于 0；
3. “损坏”是否大于 0；
4. “本地已有”是否小于“网站应有”。

因此，即使下载程序退出码为 0，只要报告显示缺图，仍会判定为未完成。

四、输出文件

扫描目录下会新建：

未完成检测结果_年月日-时分秒\
├─ 未完成检测报告.txt
├─ selected_id.txt
└─ JM连续下载ID_逗号分隔.txt

“selected_id.txt”只包含未完成作品的 JM 号，可以复制到下载工具中续传。
“JM连续下载ID_逗号分隔.txt”把所有号码放在同一行，例如：

19698,22728,27129,27143,340970,6013,77254

这一行会同时显示在检测窗口的“【可直接复制到 JM 连续下载】”下面，
可直接整行选中并复制到支持逗号分隔、批量输入的 JM 下载脚本。
每次检测使用新的时间戳文件夹，不会覆盖以前的结果。

五、运行条件

Windows 10/11；需要已安装 Python 3。
如果 JMComic 下载工具可以运行，一般已经具备 Python 环境。
