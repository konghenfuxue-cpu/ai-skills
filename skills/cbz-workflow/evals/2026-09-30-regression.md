# 本地脚本优化回归

环境：Windows、Python 3.11.9。本次只使用程序生成的小型样本，不连接下载站点。

- 页数元数据：原简介、作者、未知 XML 字段及 ZIP 元数据保留；重复运行不重复追加页数。
- 图片通过 1 MiB 缓冲复制；测试禁止通过 ZipFile.read 整体读取图片条目。同名条目的各自字节保留。
- 替换遇到 PermissionError：原 CBZ 字节不变，临时文件移除。
- 正常分卷可解析、可解码，缩放尺寸和作者元数据正确。
- 正文和公告写入异常及 KeyboardInterrupt：原输出不变，临时文件清理。
- ZIP 校验失败：不覆盖原输出。
- 模拟站点返回缺页、坏图及请求失败：各项分别出现在完整性检查结果中。
- 本机固定直接依赖版本检查、导入及 pip check 通过；未执行真实联网下载。

运行仓库根目录的 `python -m unittest discover -s tests -v`：共 20 项通过，其中本文件涉及 7 项。GitHub Actions 的 3.11/3.12 环境待推送后验证。
