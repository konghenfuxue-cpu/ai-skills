# CBZ 漫画处理工作流

安全、稳定地处理本地 CBZ 漫画，并保留已有功能和元数据。

处理需要依赖本机路径、软件版本或用户偏好时，先读取[本地环境配置](references/local-settings.md)。

## 支持的任务

- 检查 CBZ 完整性和图片页数；
- 合并、拆分或重命名 CBZ；
- 写入作者、页数和其他 `ComicInfo.xml` 元数据；
- 分析漫画下载缺页报告；
- 处理大于 2 GB 的 CBZ；
- 为 Calibre 和 Calibre-Web 整理元数据。

## 工具选择

- 页数与元数据：使用 `scripts/pagecount-metadata/`。
- 可逆合并与拆分：使用 `scripts/reversible-merge-split/`。
- 删除指定子合集：使用 `scripts/remove-subcollection/`；执行删除前必须确认目标。
- JM 分卷完整性报告：使用 `scripts/jm-report-check/`。
- JMComic 下载与打包：使用 `scripts/jmcomic-download-pack/`。

运行任一工具前先阅读同目录的 `使用说明.txt`，首次处理真实文件时使用副本。

## 处理原则

1. 先检查输入文件和现有元数据，再决定修改方式。
2. 保留有效但无法识别的原字段，不清空标题、作者、系列、卷号或简介。
3. 新内容需要加入已有简介时，换行追加。
4. 支持中文、日文、空格和特殊字符路径。
5. 大文件使用流式复制或临时 ZIP 重建，不把整个 CBZ 一次读入内存。
6. 普通元数据处理默认原地更新；新脚本先用少量测试副本验证。
7. 覆盖、删除原文件或删除子合集前，明确列出目标并取得用户确认。
8. 临时文件不得遗留在漫画目录中。
9. 不把真实漫画文件复制进 Skill 仓库。

## 修改现有脚本

1. 阅读完整脚本和使用说明，列出现有功能。
2. 明确本次新增或修复内容，保留不冲突的旧功能。
3. 检查中文路径、大文件和异常处理。
4. 修改后执行语法检查，并用小型测试文件验证。
5. 更新使用说明，报告修改、测试结果和已知限制。

## 元数据与页数

- 页数按压缩包内实际漫画图片数量计算，不包含 `ComicInfo.xml`。
- 至少识别 JPG、JPEG、PNG、WEBP、GIF 和 AVIF。
- 忽略系统隐藏文件和非图片文件。
- 写回后验证 XML 可以解析。

## 合并与拆分

- 对卷号和章节号使用自然排序，正确处理 `1`、`2`、`6`、`6.5`、`10`。
- 合并时避免不同来源出现重复图片文件名。
- 默认保留原始 CBZ；合并后重新统计页数、更新元数据并验证压缩包。
- 拆分或删除子合集前，显示名称、页数和范围；处理后重新计算总页数并检查顺序。

## 下载完整性

- 提取作品 ID、章节 ID 和作品名。
- 比较应下载与实际下载图片数，区分网络失败、图片源失效和打包失败。
- 对重复 ID 去重，输出可复制的重新下载清单。
- 已生成 CBZ 不等于下载完整。

## 验证与报告

每次修改后至少确认：文件存在且非空、ZIP 结构可读、XML 可解析、图片数量和排序正确、原元数据未意外清空、无遗留临时文件。

验证失败时不得报告成功或继续覆盖原文件，并保留错误信息及恢复建议。

最终报告扫描数、成功数、跳过数、失败数、修改内容、输出位置和需要人工检查的项目。
