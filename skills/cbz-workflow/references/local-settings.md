# 本地环境配置

## 默认路径

- JMComic 下载目录：`D:\JMComic\download`
- CBZ 目录：`D:\JMComic\download\CBZ`
- 漫画整理目录：`D:\桌面\文本\漫画`

## 软件

- Windows 11
- PowerShell 7
- Python 3
- Calibre 9.x
- Calibre-Web
- OpenComic

## 用户偏好

- 批量元数据处理默认不生成备份，尽量原地更新 CBZ；
- 第一次运行新脚本时使用测试副本；
- 保留原简介和原元数据，新内容换行追加；
- 处理结束后显示成功、失败和跳过数量；
- 支持 2 GB 以上的 CBZ；
- CMD 文件需要兼容中文路径和 UTF-8 编码。
