# TXT 转 EPUB 模板

使用 `scripts/txt_to_epub.py`。模板采用透明的阅读器默认正文背景、全页自适应封面、双层卡片简介页和独立制作说明页；不包含参考书正文、封面或专属元数据。默认不嵌入字体，以提高阅读器兼容性。

## 转换

```powershell
python scripts/txt_to_epub.py "原稿.txt" --title "书名" --author "作者" --output "书名.epub"
```

可选参数：

- `--cover 封面.jpg`：使用指定封面；省略时生成文字 SVG 封面。
- `--description "简介"`：写入元数据并生成简介页。省略时将第一个章节标题前的文字作为简介。
- `--language zh-CN`：覆盖默认语言。
- `--production-team "黑背雪"`：制作团队，默认“黑背雪”。
- `--source-provider "网友"`：校对版提供者，默认“网友”。
- `--edition "1.0"`：制作版本，默认“1.0”。
- `--production-date "2026.09.28"`：制作日期；省略时使用当天日期。
- `--layout-reference "鬼鬼、湖心溪露等大佬"`：制作说明页底部的排版参考致谢。
- `--no-production-note`：明确不生成制作说明页。
- `--keep-source-ads`：保留 TXT 中明确的来源与推广信息；默认删除。

脚本识别 `第…卷`、`第…章/节/回`、`尾声`、`终章`、`番外…`、`后日谈`、`附录`、`完本感言`。卷标题在目录中作为一级节点，后续章节作为子项；无卷结构时使用平级目录。

## 多看兼容

每本书同时生成 EPUB 3 的 `nav.xhtml` 和旧阅读内核使用的 `toc.ncx`；两套目录必须保持标题、层级、顺序和目标一致。OPF 同时声明 `properties="nav"`、NCX、`spine toc="ncx"`、EPUB 3 封面属性和旧式封面元数据，并保留 cover/toc guide。CSS 为变量、`min()` 和 flex 布局提供基础回退值。

JPG、PNG 封面兼容性最好。SVG 与 WebP 仍可使用，但旧版多看或旧电纸书固件可能无法显示书架缩略图；用户以多看为主要阅读器时优先使用 JPG 或 PNG。

## 尾部目录层级

- `完本感言` 始终作为一级目录，不归入最后一卷。
- 只对书末连续出现的番外建立一级“番外”分组，并把这些番外章节作为子目录；完本感言位于番外前后均不影响识别。
- 正文章节之间夹杂的番外保留原位置，不建立番外分组。
- 目录分组不改变原番外章节的相对顺序。生成真实的“番外”分组页，将它放在首篇末尾番外之前；目录父级必须用 `<a>` 链接到该页，禁止使用无 `href` 的 `<span>` 伪节点。分组页列出并链接全部子番外，确保 Calibre 等会尝试打开父级的阅读器不会提示“目标不存在”。

## 非作者广告清理

默认删除明确的非作者来源或推广行，例如“本文件来自某书院”“发布页：某网站”、下载站宣传、书友群、公众号取资源提示，以及紧邻这些广告的装饰分隔线。清理规则应保持保守：不得仅因正文提到网站、群聊或公众号就删除作者内容，也不得删除作者序言、后记、章节分隔或版权页中的实质信息。需要原样保留时使用 `--keep-source-ads`。

## 完成标准

1. 脚本以独占方式创建输出，不覆盖已存在的文件；写入异常或 Ctrl+C 时删除本次半成品。需要替换已有文件时先让用户明确确认或换名输出。
2. 检查 ZIP 首项为未压缩的 `mimetype`，并验证 container、OPF、manifest、spine、nav 和所有引用目标。
3. 抽查封面、简介、制作说明、第一章、最后一章及目录跳转；若有 Calibre 或目标阅读器，再进行人工打开确认。
4. 报告识别出的正文分段数量、卷数、输出路径，以及未被识别为标题的异常行（如有）。
5. 报告删除的来源或推广行数量，并抽查成品正文中不再出现对应广告。
6. 有完本感言或番外时，检查完本感言为一级目录，并确认只有末尾连续番外被归入“番外”父级。
7. 检查“番外”父级具有可解析的 `href`，目标 XHTML 已写入 manifest 和 spine，且位于首篇末尾番外之前；分组页中的每个子章节链接都实际存在。
8. 检查 `nav.xhtml` 与 `toc.ncx` 的标题、层级、顺序和跳转目标一致，并确认 NCX、旧式封面声明和 guide 已写入 OPF。
