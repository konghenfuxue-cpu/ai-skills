# 纠错记忆

用私人纠错记录改善后续任务。这个 Skill 可以公开分享；具体纠错条目由使用者保存在仓库之外。

## 找到私人记录

先遵循当前会话或项目指明的记录路径；若未指定，读取本 Skill 安装目录下的 `references/local-settings.md`（如存在）。仍找不到时，询问使用者记录位置；不要猜测个人目录，也不要在公开 Skill 中写入本机绝对路径。记录不可访问时说明限制，继续处理当前任务，不声称已应用记录。

## 处理纠错

先修复当前任务。用户明确要求记住，或指出同类错误反复发生时，再读取私人记录并新增或合并条目。保留反馈本意，记录适用场景、下次可执行的检查、证据状态和日期。没有具体失败样本时，根因写“未确认”；不要把推测写成事实。给条目稳定 ID，便于后续修改或停用。

## 用于后续任务

任务与条目的触发场景匹配时，读取相关条目并执行其中的检查。当前用户要求和实际环境优先于旧记录。只应用相关且启用的条目；交付时简短说明检查及实测结果，无法验证则明确标记。

## 维护边界

- 分开维护启用状态与证据状态：用户报告、已复现、修复已验证并不等同。
- 新证据推翻旧结论时修订原条目并保留简短说明；合并重复项。
- 私人记录不进入公开仓库；不保存凭据、聊天原文、一次性路径或未经证实的根因。
