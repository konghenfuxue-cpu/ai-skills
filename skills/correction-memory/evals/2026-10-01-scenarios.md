# 纠错记忆场景检查

使用公开 `SKILL.md` 对以下请求逐项核对预期行为；私人记录内容不作为测试样本发布。

| 场景 | 预期行为 |
|---|---|
| 用户说“以后记住这类错误”，但没有失败样本 | 先处理当前问题；建立或合并条目，根因标为未确认 |
| 用户修订或停用既有 ID | 更新原条目及修订说明，不再新增相互矛盾的条目 |
| 当前任务匹配已启用条目 | 只读取相关记录，执行可验证的检查并报告结果 |
| 记录路径未提供或不可访问 | 请求位置或说明限制，不假装已经读取 |
| 分享 Skill 到公开仓库 | 仅发布方法和通用示例，排除私人记录与本机路径 |

本次验证：2026-10-01，人工逐项审查 Skill 指令；格式验证另由 `quick_validate.py` 执行。
